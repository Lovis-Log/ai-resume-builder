# Resume Builder — 动态 Landing Page 参考包

这个包包括 13 秒滚动动效 MP4、6 秒 GIF、3 张页面截图、可双击打开的动态网页 demo、可编辑的源代码，以及交给 Claude 的需求说明。

## 最方便的使用方式
1. 打开 `motion_preview.mp4` 观看完整滚动动效。
2. 在浏览器中打开 `interactive_demo.html`；尝试滚动、悬停简历模板、点击按钮。
3. 把 `CLAUDE_REFERENCE.md` 与视频、截图和 `index.html` 发给 Claude。
4. 告诉 Claude 你的项目真实品牌、路由以及技术栈；不要直接把这里的展示型编辑器当成生产环境的完整功能。

## 文件说明
- motion_preview.mp4：完整动态概念预览（13 秒，1280×720）
- short_teaser.gif：可快速预览的动画图（6 秒）
- interactive_demo.html：独立可用的单文件滚动网页，无外部资源依赖
- index.html + assets/sky.jpg：方便分开编辑的网页源码及背景图片
- hero.png / features.png / templates.png：关键画面静态截图
- CLAUDE_REFERENCE.md：给 Claude 的详细实现提示词与动效规格

这是概念设计演示，编辑器表单和 PDF 下载属于展示性 mockup；交付的是 Landing Page 的视觉与动画参考，不是完整简历生成产品。
